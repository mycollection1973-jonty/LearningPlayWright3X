# VS Code Keyboard Shortcuts — Windows

## General

| Command | Shortcut | Description |
|---|---|---|
| Command Palette | `Ctrl + Shift + P` | Open all available commands |
| Quick Open (File) | `Ctrl + P` | Search and open files by name |
| Settings | `Ctrl + ,` | Open User Settings |
| Keyboard Shortcuts | `Ctrl + K Ctrl + S` | View/edit keyboard shortcuts |
| Terminal | `` Ctrl + ` `` | Toggle integrated terminal |
| Toggle Sidebar | `Ctrl + B` | Show/hide left sidebar |
| Full Screen | `F11` | Toggle full screen |
| Zen Mode | `Ctrl + K Z` | Distraction-free mode |

## Editing

| Command | Shortcut | Description |
|---|---|---|
| Copy Line | `Ctrl + C` (no selection) | Copy entire line |
| Cut Line | `Ctrl + X` (no selection) | Cut entire line |
| Move Line Up/Down | `Alt + ↑ / ↓` | Move current line |
| Duplicate Line | `Shift + Alt + ↑ / ↓` | Copy line above/below |
| Delete Line | `Ctrl + Shift + K` | Delete entire line |
| Insert Line Below | `Ctrl + Enter` | Insert blank line below |
| Insert Line Above | `Ctrl + Shift + Enter` | Insert blank line above |
| Indent / Outdent | `Tab` / `Shift + Tab` | Increase/decrease indentation |
| Go to Line | `Ctrl + G` | Jump to a specific line number |
| Go to Matching Bracket | `Ctrl + Shift + \` | Jump between `{}` `()` `[]` |
| Fold / Unfold | `Ctrl + Shift + [` / `]` | Collapse/expand code block |

## Multi-Cursor & Selection

| Command | Shortcut | Description |
|---|---|---|
| Add Cursor Above/Below | `Ctrl + Alt + ↑ / ↓` | Multiple cursors |

| Add Next Occurrence | `Ctrl + D` | Select next occurrence of current word |
| Column Select (Box) | `Shift + Alt + Drag` | Rectangular selection |
| Expand Selection | `Shift + Alt + →` | Smart expand selection |

## Search & Replace

| Command | Shortcut | Description |

| Replace in All Files | `Ctrl + Shift + H` | Find and replace across project |

## Navigation

|---|---|---|
| Go to Definition | `F12` | Jump to symbol definition |
| Peek Definition | `Alt + F12` | Inline peek at definition |
| Go to References | `Shift + F12` | Show all references |

## Source Control (Git)

| Command | Shortcut | Description |
|---|---|---|
| Source Control Panel | `Ctrl + Shift + G` | Open Git panel |
| Stage Changes | `Ctrl + Shift + G` then `S` | Stage selected file |
| Commit | `Ctrl + Enter` (in commit box) | Commit staged changes |
| Pull | `Ctrl + Shift + P` → Git Pull | Pull from remote |
| Push | `Ctrl + Shift + P` → Git Push | Push to remote |

## Terminal

| Command | Shortcut | Description |
|---|---|---|
| New Terminal | `` Ctrl + Shift + ` `` | Create new terminal instance |
| Kill Terminal | `Ctrl + Shift + K` (in terminal) | Close active terminal |
| Switch Terminal | `Alt + ↑ / ↓` | Cycle between terminals |
| Clear Terminal | `Ctrl + Shift + L` | Clear terminal output |

---

## Key Takeaways

1. `Ctrl + Shift + P` — the most important shortcut (opens everything)
2. `Ctrl + P` — fastest way to open any file
3. `Ctrl + D` for quick multi-cursor editing
4. `Ctrl + /` for toggling comments
5. `Ctrl + \`` for terminal toggle
